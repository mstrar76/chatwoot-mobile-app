# Tendeo brand

Source: Claude Design project "Tendeo" (05 Entregaveis e Prompts).

- Display name: Tendeo — "Atenda os clientes de todas as suas empresas em um só app."
- Primary #4A3AC7, secondary #F4B63F, splash background #4A3AC7, font Manrope.
- Symbol: two white pills (bar over a short stem) on indigo; geometry in `generate.py`.

`python3 branding/tendeo/generate.py` renders `assets/icon.png`, `assets/adaptive-icon.png`,
`assets/splash.png` and `src/assets/images/logo.png`. Build env: `EXPO_PUBLIC_APP_NAME=Tendeo`,
`EXPO_PUBLIC_BRAND_COLOR=#4A3AC7` (see `.env.example`).
